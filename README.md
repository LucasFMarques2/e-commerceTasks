# E-commerce

Projeto realizado para teste seletivo da empresa filter

## Tecnologias Utilizadas

- **Front-end**: React + Vite
- **Back-end**: Node.js + Express
- **Integração de API**: Axios
- **Estilização**: Styled-componets.css
- **Gerenciamento de Pacotes**: NPM
- **Ícones**: React-icons
- **Banco de dados**: MongoDB

## Funcionalidades backend

- CRUD de protudos
- Criar usuário
- Adicionar produtos a lista de desejo do usuário
- Adicionar produtos a lista de comprados do usuário

## Funcionalidades Frontend

- Lista de produtos
- Filtro de produtos por nome
- Compra de produtos
- criação de usuários
- Login de usuário

## Instruções para Execução Local

### Backend

Para executar a aplicação em sua máquina local, siga os seguintes passos:

1. Clone o repositório:
   ```bash
   git clone https://github.com/LucasFMarques2/e-commerceTasks
2. Abra a pasta e-commerceTasks e entre na pasta backend.
3. renomei o arquivo exemple.env para .env
4. preencha os campos solicitados
5. certifique-se que o Node esteja instalado na sua máquina
6. Abra o terminal da pasta e rode o comando
   ```bash
   npm install
7. Após instalar os pacotes, rode o comando
      ```bash
   npm run dev
8. e se tudo der certo a aplicação vai rodar, geralmente roda na porta 3333

### Frontend

Para executar a aplicação em sua máquina local, siga os seguintes passos:

1. Clone o repositório:
   ```bash
   git clone https://github.com/LucasFMarques2/e-commerceTasks
2. Abra a pasta e-commerceTasks e entre na pasta frontend.
3. renomei o arquivo exemple.env para .env
4. preencha os campos solicitados com a rota da API
5. certifique-se que o Node esteja instalado na sua máquina
6. Abra o terminal da pasta e rode o comando

7. Após instalar os pacotes, rode o comando

8. e se tudo der certo a aplicação vai rodar
